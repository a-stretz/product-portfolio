# Austin Stretz — Product Portfolio

Case studies and independent builds in AI product management: model evaluation,
knowledge codification, agentic workflows, and applied decision systems.

**Live site:** open `index.html` (or serve the repo root — this is a static
site, no build step).

- `index.html` — homepage; same content as `case-studies.html` (see below)
- `case-studies.html` — the main portfolio: five cases, evidence-tagged as
  production work, independent builds, or frameworks
- `case-study-01-biomechanics-qa.html` — full deep-dive, Case 01
- `career-workflow-case-study.html` / `probability-engine-case-study.html` —
  full deep-dives, Cases 03 / 05
- `full-report.html` — the AI Product Value Creation Framework (Case 04
  reference), rendered client-side from `report-part*.jsx` / `diagrams.jsx` /
  `tweaks-panel.jsx`
- `assessment/` — interactive AI Readiness Assessment (Case 04); source in
  `assessment/src`, built output served from `assessment/dist`
- `styles.css` / `case-study-detail.css` — shared design tokens

`index.html` and `case-studies.html` are intentionally duplicated content
rather than one redirecting to the other, so that anchor links like `#c4`
resolve reliably regardless of which URL a link points to.
