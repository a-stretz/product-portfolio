Case Study01

Scalable Expert Knowledge Codification Framework for Motion Evaluation.

Knowledge Engineering Heuristic Framework Interpretability Modular System Design
Evidence: Production system · NeoSavant.ai

Designed and implemented a framework to translate expert coaching knowledge into structured, scalable system logic. Replaced a rigid single-expert model with a flexible evaluation system supporting multiple users, skill levels, and sports, built in part to resolve structural flaws in the heuristic logic identified during Case 01.

Environment
& Systems
  • Computer vision platform analyzing human movement
  • Heuristic evaluation layer defining optimal technique
  • Domain expertise sourced from subject matter experts
01 · Problem

One expert, hardcoded, un-auditable.

The system relied on a single expert's interpretation of optimal technique, hardcoded directly into the model. The result:

  • No adaptability across users or contexts
  • Incomplete or incorrect translation of expert intent
  • No transparency in how evaluations were generated
  • No scalable path to new sports or use cases
02 · Approach

Expert reasoning as a modular layer.

  • Designed a structured extraction process to capture expert decision logic, separating what the expert meant from how it had been implemented
  • Translated qualitative coaching expertise into standardized metrics and evaluation rules
  • Built a reusable heuristic framework template configurable per sport, skill level, and user profile
  • Developed a Master Metric Inventory capturing all relevant evaluation signals across movement types
  • Incorporated research and multiple expert perspectives to eliminate single-source dependency
03 · Key Decisions

Configurable over fixed.

  • Replaced hardcoded logic with a modular, interpretable framework: evaluation criteria as configurable components rather than fixed rules
  • Separated domain knowledge from implementation so expert reasoning could be updated without engineering changes
  • Designed for interpretability so both technical and non-technical stakeholders could understand and audit evaluation logic
04 · Impact

From one-time build to persistent capability.

  • Standardized and corrected how expert knowledge was represented, resolving structural flaws identified during model evaluation
  • Enabled configurable evaluation across users, skill levels, and contexts without new development per variation
  • Created a scalable foundation for expanding beyond a single sport into multi-sport motion analysis
  • Transformed expert knowledge from a one-time implementation into a persistent, auditable, extendable capability
Case Study03

AI Career Workflow System to enable Job Seekers to put their true best foot forward.

Agentic Workflow Hybrid Reasoning Shared Knowledge Base End-to-End Build
Evidence: Independent build · Self-directed prototype

Designed and built an AI-powered system supporting job search, application generation, and interview preparation through a unified knowledge base, built in response to a hiring landscape where AI-generated noise is degrading quality on both sides of the process.  → Read the full case study

Environment
& Systems
  • Multi-step AI workflow system combining structured data and LLM reasoning
  • Hybrid system using deterministic logic and AI generation
  • Reusable knowledge base supporting multiple outputs
01 · Problem

An arms race of generic output.

Candidates flood roles with automated, generic applications. Companies post AI-written job descriptions through applicant tracking systems that use AI screening. Authenticity has been stripped out on every side, and qualified candidates are lost in the noise.

The candidate experience itself is fragmented: every application rebuilds context from scratch, outputs are inconsistent, and effort scales linearly with every opportunity pursued.

02 · Approach

One source of truth, many outputs.

  • Built a structured knowledge base containing professional stories, proof points, skills, and positioning as a single source of truth across all workflows
  • Designed connected workflows spanning job analysis, application tailoring, and interview preparation, each pulling from the same foundation
  • Implemented hybrid logic combining deterministic rules (role matching, requirement mapping) with AI-driven generation (cover letters, interview strategy)
  • Created reusable outputs so research, positioning, and preparation compound across opportunities rather than starting fresh each time
03 · Key Decisions

Knowledge reuse over prompt proliferation.

  • Centered the system on knowledge reuse rather than isolated prompt generation, so every interaction builds on previous work
  • Combined deterministic logic with model-driven reasoning to maintain consistency while allowing contextual adaptation
  • Designed to surface genuine, relevant experience rather than optimizing for ATS keyword games
04 · Impact

Built for reuse, not yet externally validated.

  • Replaced repeated, from-scratch application work with one shared knowledge base reused across every opportunity
  • Designed to keep candidate experience and role requirements aligned across every submission, rather than optimizing for ATS keyword matching
  • Currently a single-candidate prototype built and used for the author's own job search; external validation across other candidates is the next step
  • Introduces a knowledge-reuse approach to AI-assisted job search, prioritizing grounded, genuine candidate experience over generic output

Case Study03

AI Model Performance QA Evaluation System for a Computer Vision Platform.

Evaluation Infrastructure Computer Vision Biomechanics LLM-as-Judge Ground-Truth Engineering
Evidence: Production system · NeoSavant.ai

Built the platform's first evaluation system for a computer vision product generating biomechanical analysis from pose estimation data. The core value proposition was precision, but no infrastructure existed to verify whether that claim was true. Established a structured evaluation framework combining statistical validation, manual annotation, and LLM-as-a-Judge to determine output reliability and system limitations.  → Read the full case study

Environment
& Systems
  • Computer vision platform generating biomechanical metrics from pose estimation
  • Multi-stage evaluation system validating model outputs and interpretation quality
  • Pipeline combining statistical analysis, manual validation, and AI-based assessment
01 · Problem

Precision claims with no way to prove them.

The platform produced biomechanical analysis, but there was no mechanism to measure metric accuracy, assess model reliability, or determine where outputs broke down. The entire product strategy depended on delivering precision no competitor had achieved — yet the product was making claims it couldn't substantiate.

Risk surface

  • Metric accuracy and consistency
  • Instability from noisy or occluded keypoints
  • No ground-truth validation
  • Unverified outputs presented as reliable
02 · Approach

Multi-stage evaluation as a core capability.

  • Designed and built a multi-stage evaluation system covering model output validation, measurement precision, and interpretation quality
  • Established ground truth through manual annotation and structured comparison against validated reference data
  • Implemented jitter analysis to quantify measurement instability across configurations and movement phases
  • Introduced LLM-as-a-Judge to assess output reasoning quality beyond statistical accuracy
  • Built the system using AI-assisted development workflows while maintaining full ownership of design and validation logic
03 · Key Decisions

Evaluation treated as a product, not QA.

  • Treated evaluation as a core product capability required before credible market positioning, not a post-launch QA step
  • Separated measurement validation (are the numbers right?) from interpretation evaluation (are the conclusions sound?)
  • Used statistical methods for accuracy verification and LLM-based evaluation for output quality, each applied where most appropriate
  • Prioritized surfacing system limitations honestly over forcing outputs that couldn't be trusted
04 · Impact

Precision made measurable.

This was the platform's first method for evaluating AI model performance. Before this system, there was no way to verify whether the metrics, the heuristic scoring, or the keypoint detection models were producing reliable results.

  • Processed 600+ tracked events and 24,000 manually reviewed frames through validation workflows
  • Identified primary sources of data instability and error propagation affecting downstream outputs
  • Enabled targeted model and pipeline corrections from observed failure patterns
  • Exposed logical flaws in the heuristic framework, directly informing the redesign in Case 02

Case Study04

Framework for Evaluating Readiness of AI-Product Development for Value Creation

Diagnostic Framework B2B SaaS Portfolios Gating Constraints
Evidence: Framework · Self-directed, interactive prototype

Developed a structured diagnostic framework for evaluating AI readiness, prioritizing opportunities, and guiding execution across B2B SaaS portfolios, built independently as a self-directed framework for organizations navigating AI adoption decisions.  → Read the full report  → Try the interactive assessment

Environment
& Systems
  • Multi-company B2B SaaS environments
  • Cross-functional product, data, and business teams
  • AI strategy and execution planning
01 · Problem

Knowing AI matters ≠ knowing what to do.

Most B2B SaaS companies face the same challenge: they know AI is relevant but lack a consistent method to evaluate where it matters, what's actually ready, and how to sequence investments.

Without a structured approach, companies either invest prematurely in capabilities they can't support, or delay meaningful initiatives because they can't distinguish high-value opportunities from noise.

02 · Approach

Six stages, eight diagnostics, one playbook.

  • Built a six-stage framework spanning initial diagnostics through execution validation and compounding returns
  • Defined AI Readiness Levels with gating constraints that prevent organizations from advancing to initiatives their infrastructure, data, or teams can't support
  • Structured evaluation across eight dimensions: business value, product integration, data maturity, technical feasibility, UX, risk, competitive positioning, operational readiness
  • Designed composite scoring with weighted grading for consistent comparison across opportunities and organizations
03 · Key Decisions

Decisions, not assessments.

  • Used gating constraints as a core mechanism: diagnostic outputs drive realistic execution plans rather than aspirational roadmaps
  • Linked every diagnostic finding directly to a concrete execution action so the framework produces decisions, not just assessments
  • Designed to distinguish between cases requiring genuine AI product development and cases where existing SaaS capabilities with simple automation would deliver equivalent value
04 · Impact

Built as a working tool, not just a report.

  • Produced a complete diagnostic framework for evaluating AI adoption across B2B SaaS portfolios, built independently and not yet applied to a live client engagement
  • Implemented as an interactive assessment: an 8-section weighted diagnostic with gating logic and intervention-path recommendations, not just a static write-up
  • Provides a structured method for determining when AI investment is warranted, where simpler solutions are sufficient, and what sequence of work will produce the highest return
  • The scoring weights and gating thresholds are a first-pass model, not yet pressure-tested against a real portfolio or company
Case Study05

Interactive Probability Engine for Tournament Outcome Modeling.

Real-Time Analytics Exhaustive Enumeration Solo Delivery End-to-End System
Evidence: Independent build · Solo project

Designed and built a real-time probability engine to model all possible tournament outcomes and determine participant win likelihood, delivered as a fully functional analytical tool during a live event window.  → Read the full case study

Environment
& Systems
  • Semi-structured data with no API access
  • Client-side application with custom scoring and probability logic
  • Real-time updates based on live event outcomes
01 · Problem

No visibility into cascading outcomes.

Participants in a tournament pool had no way to understand their win likelihood, which game outcomes would help or eliminate them, or how scenarios would cascade through the remaining bracket.

02 · Approach

Exact probabilities through enumeration.

  • Extracted and structured participant data from unstructured inputs with no API available
  • Built a scoring engine aligned to custom pool rules and tiebreaker logic
  • Designed a probability engine using exhaustive scenario enumeration for exact outcome probabilities rather than approximations
  • Created an interactive interface for real-time scenario modeling with cascading effects on standings
03 · Key Decisions

Exactness over simulation.

  • Used exhaustive enumeration over Monte Carlo simulation to provide exact probabilities, feasible given the bounded outcome space
  • Designed dependency propagation so each game outcome correctly cascaded through all downstream scenarios
  • Optimized for rapid deployment: built and shipped a complete tool within the live event window
04 · Impact

Shipped, live, standalone.

  • Delivered a working analytical tool supporting real-time engagement during a live event
  • Modeled all possible outcomes, elimination paths, and exact win-probability distributions
  • Demonstrated end-to-end system design, build, and deployment as a solo effort under tight time constraints
